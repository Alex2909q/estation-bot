# Exam 1843 — сторож талонів на практичний іспит (Коростень)

Кожні 15 хвилин перевіряє, чи з'явився вільний талон на практичний іспит у **ТСЦ МВС № 1843**
(м. Коростень, вул. С. Кемського, 3), і пише про це в Telegram контакту **«Голубоглазка Оля»**
від вашого імені.

## Чому через ТалонБот, а не напряму із сайту

Е-запис (eqn.hsc.gov.ua) показує талони лише після входу через ID.GOV.UA (КЕП / BankID / Дія)
і стоїть за антибот-захистом Akamai. Сесія входу живе недовго, а сервери GitHub захист не пройдуть.
Офіційний **ТалонБот** ГСЦ МВС сам перевіряє вільні талони в обраному ТСЦ, тож скрипт стежить
за вашим чатом з ним і пересилає Олі нові сповіщення.

## Налаштування (один раз, ~10 хв)

1. **ТалонБот.** У Telegram знайдіть пошуком «ТалонБот» (офіційний бот ГСЦ МВС) → «Почати» →
   поділіться контактом → послуга «Практичний іспит» → категорія та коробка передач (як у Олі) →
   Житомирська область → ТСЦ № 1843 Коростень → «Так, я хочу отримувати інформацію про талони».
2. **Окрема сесія Telegram.** Запустіть `make_session.command` ще раз — отриманий рядок збережіть
   у секреті **`EXAM_SESSION`** (GitHub → Settings → Secrets and variables → Actions).
   Не беріть наявну `TG_SESSION`: одна сесія одночасно у двох workflow відкликається Telegram.
3. *(Необов'язково)* секрет **`EXAM_TALON_BOT`** = @username ТалонБота. Без нього скрипт сам знайде
   бота з «талон» у назві серед ваших чатів.
4. **Тест.** Actions → **Exam 1843** → Run workflow → увімкніть «Тестовий режим». Сповіщення підуть
   у ваше «Збережене», Олі нічого не надійде.
5. **Бойовий запуск.** Run workflow без тестового режиму. Далі воно крутиться саме.

Коли Оля запишеться: Actions → Exam 1843 → ⋯ → **Disable workflow**, а в ТалонБоті скасуйте відстеження.
