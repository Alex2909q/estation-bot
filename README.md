# EStation: оголошення про зарядні станції з Telegram

Перевіряє Telegram-канали знижок і, коли з'являється пост про зарядну станцію
(EcoFlow, Bluetti, OSCAL, IEE, «зарядна станція», «1800W / 1024Wh» тощо), бот
@EstationC_bot надсилає вам текст і **пряме посилання на пост**.

```
🔋 Нове оголошення: зарядна станція
👥 ZBS Kitai
🕒 24.10.2026 10:32
🔑 зарядн* станц*, allpowers

ТЯНЕТ ВСЁ⚡ Зарядная станция ALLPOWERS для КВАРТИРЫ …

🔗 https://t.me/ZBSkitai/2439          [ Відкрити оголошення ]
```

Канали — у `channels.txt`, ключові слова — у `keywords.txt`, виключення — у `exclude.txt`.
Ці файли можна редагувати прямо на GitHub (олівець ✏️ → Commit).

## Варіант 1. GitHub Actions (нічого не треба тримати увімкненим)

Працює на серверах GitHub за розкладом, **приблизно кожні 5 хвилин** (частіше GitHub
не дозволяє; у години пік запуск може запізнитися — пости при цьому не губляться).

1. **Репозиторій має бути публічним** — тоді GitHub Actions безкоштовні без ліміту.
   У приватному безкоштовно лише 2000 хв/місяць — цього вистачить на перевірку раз на 30 хв.
   Токени в публічному репозиторії ніхто не бачить: вони зберігаються як Secrets.
2. **Secrets.** Settings → Secrets and variables → Actions → **New repository secret**:
   - `BOT_TOKEN` — токен @EstationC_bot від @BotFather (обов'язково).
3. Відкрийте @EstationC_bot у Telegram і натисніть **Start**.
4. Вкладка **Actions** → **Monitor** → **Run workflow**. Через хвилину бот напише
   «✅ Моніторинг на GitHub запущено». Далі все працює саме.

Команда в боті: `/status` — стан і список каналів (відповідь приходить з наступною перевіркою, до 5 хв).

### Канали, які без акаунта не читаються (@dobrymao_UA, @dealradarua)

Решту каналів бот читає через їхню публічну веб-версію `t.me/s/<канал>`, без входу в акаунт.
У цих двох її вимкнено, тому вони читаються лише через ваш акаунт — один секрет `TG_SESSION`:

1. На Mac у папці з ботом клацніть **правою кнопкою** на `make_session.command` → **Відкрити**.
2. Введіть номер телефону й код із Telegram. Секрет автоматично скопіюється в буфер обміну.
3. Settings → Secrets and variables → Actions → New repository secret: Name `TG_SESSION`, Secret — Cmd+V.

Поки `TG_SESSION` немає, бот раз на день нагадує, які канали пропускає.
`TG_SESSION` — це доступ до вашого акаунта: зберігайте лише в Secrets.
Відкликати: Telegram → Налаштування → Пристрої → «EStation GitHub» → Завершити.

## Варіант 2. На своєму Mac (перевірка щохвилини)

`.env` уже містить токен бота та API-ключі.

1. Клацніть **правою кнопкою** на `start.command` → **Відкрити** → **Відкрити**.
2. У вікні Терміналу введіть номер телефону й код із Telegram (лише перший раз).
3. Для роботи у фоні з автозапуском — `autostart-on.command`, вимкнути — `autostart-off.command`.

Не запускайте обидва варіанти одночасно: будуть дублікати сповіщень.

## Ключові слова (`keywords.txt`)

- `*` — будь-яке закінчення: `зарядн* станц*` = «зарядна станція», «зарядную станцию»…
- слова в ключі знаходяться і через пробіл, і через дефіс, і разом;
- `ЕсоFlow` з кириличними літерами теж розпізнається;
- `re:...` — регулярний вираз; після двох пробілів і `#` — підпис для сповіщення.

Відстежуються погоджені бренди: EcoFlow, Bluetti, Jackery, Anker (лише SOLIX/PowerHouse), Allpowers,
Fossibot, TALLPOWER, Vtoman, Necespow, ABOK, AFERIY, SOLARPLAY, OSCAL (лише Max/PowerMax),
OUKITEL (лише серія P/BP), IEE/IEETek (серія P), Newsmy (лише з ємністю у Wh) і їхні моделі —
плюс загальні назви («зарядна станція», «power station») та ємність від 200 Wh.
Павербанки, зарядки, кабелі, смартфони OSCAL/Oukitel/Fossibot не спрацьовують
(перевірка: `python tests/test_keywords.py`).

`exclude.txt` — слова, з якими пост ігнорується (наприклад, `куплю`).
